# 맞춤돌봄도우미

맞춤돌봄케어(goodeos) 일일실적 점검 프로그램. 실행 파일은 Releases 에서 받으세요. 새 버전이 나오면 프로그램 안에 '업데이트' 버튼이 나타납니다.


## 자동 로그인 (v1.2.0)

'로그인 정보' 버튼에서 goodeos 아이디/비밀번호를 한 번 저장하면, 이후 '점검 시작'이나 '자동화 크롬 열기'만 눌러도 크롬을 켜고 자동으로 로그인합니다. 로그인 정보는 윈도우 DPAPI로 암호화되어 `%LOCALAPPDATA%\맞춤돌봄도우미\login.dat` 에 저장되며, 같은 PC의 같은 윈도우 계정에서만 풀 수 있습니다. 코드나 저장소에는 들어가지 않습니다.

## 크롬 백그라운드 실행

로그인 정보를 저장하고 '점검할 때 크롬 창 숨기기'를 켜 두면(기본값), 점검할 때 크롬을 창 없이 백그라운드로 띄웁니다. 직접 보고 싶을 때는 '크롬 창 열기'를 누르면 창이 보이는 크롬으로 바꿔 열고 로그인까지 합니다. 백그라운드 크롬은 프로그램을 닫을 때 같이 꺼집니다.
