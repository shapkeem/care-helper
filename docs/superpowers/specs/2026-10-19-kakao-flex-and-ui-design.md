# 3.1.0 설계: 유연한 카톡 해석 + 화면 다듬기 + 버그 3개

## 목표
- 카톡을 형식 없이 붙여 넣어도 알아듣게 한다. 추가 비용 없이 Jev만 쓴다.
- 질문 수를 줄인다. 질문 방식은 지금처럼 처리 중에 하나씩 묻는 방식을 유지한다.
- 화면을 둥글고 깔끔하게 통일한다.
- 복사 버튼, 남은 파일 확인 창, 상태 표시 줄바꿈을 고친다.

## 1. 카톡 해석 (kakao.py)
역할: 코드는 후보를 넉넉히 뽑고, Jev는 후보 중에서 고른다. Jev는 글을 지어내지 않는다.

### 1-1. 메시지 나누기 (`split_messages`)
- `[대화명] [오전/오후 h:mm]` 머리줄은 지금처럼 읽는다.
- 머리줄이 없을 때:
  - 줄이 지원사 명단의 이름(또는 대화명 앞부분)으로 시작하면 새 메시지로 보고, 그 이름을 지원사로 쓴다.
  - 그 밖에는 빈 줄로 메시지를 나눈다. 빈 줄도 없으면 한 줄을 한 메시지로 본다.
- 지원사를 못 찾은 메시지는 어르신 명단의 담당 지원사로 채운다. 담당이 한 명이면 묻지 않는다.

### 1-2. 시간 후보 (`find_times`)
지금 읽는 모양(`0918~0919`, `9:18-9:19`)에 아래를 더한다.
- `2시`, `2시 반`, `2시 30분`, `14시`, `오후 2시`, `오전 9시`
- `~부터 ~까지`, `2시부터 30분`, `2시~2시반`, `30분간`, `1시간`
- 시작만 있고 길이가 없으면: 전화는 1분, 방문은 묻는다.
- 오전/오후가 없는 1~6시는 오후로 본다(근무시간 기준). 확신이 낮으면 Jev 후보로 넘긴다.

### 1-3. 날짜 후보 (`find_dates`)
지금 읽는 모양(`9/18`, `18일`, `0918`)에 아래를 더한다.
- `오늘`, `어제`, `그제/그저께`, `내일`
- `월~일요일`, `지난주 화요일`, `이번주 금요일`
- 메시지 날짜를 기준으로 계산하고, 미래가 되면 지난주로 본다.

### 1-4. Jev가 고르는 것 (`Interpreter`)
메시지 하나에 `jev.ask` 한 번으로 아래 질문을 묶어 보낸다.
- 시간 후보마다: 서비스 시간인지 / 어느 어르신 것인지(보기 = 이 메시지의 어르신 후보)
- 항목마다: 요청 종류(실적/일정등록/수정/삭제/기타), 서비스 종류(낱말이 없을 때)
- 이름 오타 맞추기, 사람 답변 해석은 지금처럼 Jev `choice`를 쓴다.

### 1-5. 질문 줄이기
- 확신도 0.7 이상이면 묻지 않는다(지금과 같음).
- 같은 메시지의 다른 항목에서 이미 답한 내용(지원사, 날짜, 요청 종류)은 다시 묻지 않고 이어 쓴다.
- 전화인데 끝 시간이 없으면 시작+1분으로 채우고 묻지 않는다.
- 요청 낱말이 메시지 끝에 한 번만 있으면 모든 항목에 적용한다(지금 규칙 유지).

### 1-6. 시험
- `test_kakao.py`를 새로 만든다. 지금 형식(머리줄 있음) 예문과 형식 없는 예문을 함께 넣는다.
  - 머리줄 없음, "어제 2시 반부터 30분", "지난주 화요일", 한 메시지에 여러 어르신.
- Jev 호출은 시험에서 가짜 응답으로 바꿔 끼운다.

## 2. 화면 (tkui.py)
승인된 시안 기준.
- 입력칸(`tk.Entry`, `tk.Text`) 전체를 공통 함수 하나로 만든다:
  - 둥근 테두리(캔버스), 연한 회색 테두리, 누르면 파란 테두리
  - 대상: 카톡 입력, 질문 답 칸, 계획자 칸, 설정의 아이디·비밀번호·Jev 키 칸
- 버튼: 알약 모양. 화면마다 파란 버튼은 하나.
- 질문 카드: 연한 파란 배경 둥근 카드. 질문 한 줄, 보기는 둥근 버튼(가로로 줄바꿈), 아래에 직접 적기 칸과 [답하기].
- 카톡 안내 문구: "카톡을 아무렇게나 붙여 넣어도 돼요".
- 결과 표: "지원사 · 어르신 · 날짜 시간 서비스 · 요청" 한 줄 + 상태 표시. **상태 표시(완료/질문 중 등)는 칸 안에서 가운데 정렬**(기존처럼).
- 다른 화면(일일실적, 변환, 서비스 제공계획 입력, 설정)도 같은 입력칸·버튼으로 맞춘다. 배치는 그대로.

## 3. 버그
- **복사 버튼**: `api.set_clipboard`의 ctypes 인자 타입을 64비트에 맞게 지정한다(`GlobalAlloc`, `GlobalLock`, `SetClipboardData` argtypes/restype). 실패하면 Tk `clipboard_append`로 대신한다.
- **남은 파일 확인**: [변환 시작]을 눌렀을 때 '작업후' 폴더에 이전 파일이 있으면 "이전 변환 파일 N개를 휴지통으로 보낼까요?" 창을 띄운다. 예 → 휴지통 후 변환, 아니오 → 그대로 변환.
- **상태 표시 줄바꿈**: `tkui.GOODEOS_TEXT["ok_hidden"]`을 "goodeos 로그인됨"으로 바꿔 한 줄에 들어가게 한다.
