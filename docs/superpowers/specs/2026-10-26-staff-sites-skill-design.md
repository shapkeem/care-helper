# 직원용 Claude 스킬 "맞춤돌봄-사이트" 설계

## 목적
기관 직원이 Claude 데스크톱 앱에서 goodeos(맞춤광장·맞광)와 s-care(에스케어·시스템·맞춤돌봄시스템)의 조회·수정을 말로 시킬 수 있게 한다. 기관 안에서만 배포한다.

## 정한 것
- 사용 환경: Claude 데스크톱 앱 (직원 PC에서 크롬을 직접 조종)
- 방식: 지도 기반(A). 미리 만든 기능 없이, 사이트 구조 지도와 범용 도구로 모든 기능을 처리한다.
- goodeos 로그인: 기관 공용 계정을 스킬의 설정 파일에 넣는다(사용자 결정). 사용법 문서에는 넣지 않아 대화 내용에 실리지 않게 한다.
- s-care 로그인: 직원이 크롬 창에서 직접 한다.
- 수정 확인: 바꿀 목록을 표로 보여 주고 한 번 확인받아 묶어서 저장한다.

## 구성
- `SKILL.md`: 부르는 말(별칭), 일하는 순서, 안전 규칙
- `references/goodeos-사이트구조.md`, `references/s-care-사이트구조.md`: 개인정보를 가린 구조 지도
- `references/노하우.md`: 페이지 20건, 대상자이력현황 기준일 조회, s-care 상담지에는 pvplId 필요, 백업 시간 0~4시, s-care가 정보의 기준 등
- `scripts/site_tool.py`: 크롬 연결(goodeos 9222 자동 로그인, s-care 9223), `read`(조회 POST/GET), `write`(확인 토큰이 있어야만 보냄, 기록 남김), `page`(화면 열어 HTML 읽기)
- `scripts/setup.ps1`: 파이썬·playwright 설치 확인
- `config/계정.json`: goodeos 공용 아이디·비밀번호 (공개 저장소에 넣지 않음)

## 안전 규칙
- 조회는 바로 한다.
- 쓰기: 지금 값 읽기 → "누구/무엇/지금 → 바꿀 값" 표 → 직원 "진행" → `write --confirm` 으로 저장 → 다시 읽어 확인 → 결과 보고.
- 쓰기 요청은 사이트 화면의 저장 버튼이 보내는 주소·값과 같게만 보낸다(지도와 화면 스크립트로 확인).
- 모든 쓰기는 `C:\맞춤돌봄도우미\스킬작업기록.log`에 남긴다.
- 개인정보는 직원 PC와 대화 안에서만 다룬다.

## 오류 처리
- goodeos 로그인 풀림 → 자동 재로그인 후 이어서
- 0~4시 → 멈추고 4시 이후 안내
- s-care 미로그인 → 창을 띄우고 로그인 요청
- 화면 끊김 → 재연결 후 이어서, 안 되면 진행 상황 보고
- 일부 실패 → 성공/실패 나눠 보고
- 화면이 지도와 다름 → 멈추고 알림

## 시험
- 조회: 이번 대화의 결과(장기부재 명단, 308명 날짜, 혹서기 실적, 연락처 비교)와 같은지
- 쓰기: 12월 시험 날짜의 일정 넣기·지우기만, 끝나면 되돌림
- 설치: 도구 설치 확인 스크립트

## 배포
- 스킬 폴더를 압축 파일로 만들어 직원 PC의 Claude에 설치를 맡긴다.
- 공개 저장소(care-helper)에는 스킬과 계정 파일을 넣지 않는다.
