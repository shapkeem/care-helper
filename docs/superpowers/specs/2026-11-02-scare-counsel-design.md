# s-care 서비스 상담지 입력 (엑셀 → s-care)

## 목적
직원이 엑셀로 쓴 상담지를 s-care 조사결과 작성중 어르신의 서비스 상담지에 그대로 넣고 저장한다.

## 정한 것 (사용자 결정 2026-11-02)
- 왼쪽에 새 메뉴 **서비스 상담지 입력** (서비스 제공계획 입력과 따로).
- 파일 받기: 화면에 **끌어다 놓기** (폴더면 안의 상담지 엑셀 전부, 파일이면 그 파일). [파일 고르기] [폴더 고르기]도 둔다.
- [양식 다운로드]: 김길임 상담지와 같은 모양의 빈 양식을 저장.
- 상담일자 = 조사결과 작성중 목록의 그 어르신 **방문일자**(`vstPoptDe`).
- 상담시각 = 표에서 어르신마다 적는다(6~23시). 비우면 **9시**.
- 상담자 = 제공계획 입력의 계획자처럼 이름으로 s-care 사용자에서 찾는다(정확히 한 명일 때만). 이 컴퓨터가 기억.
- 상담장소 = 목록의 **요청판정(수행기관의견)** `dmdSvcTyNm`이 일반이면 `유선상담`, 중점이면 `대상자 가정`.
- 엑셀 줄 앞의 `'`는 빼고 넣는다(엑셀에서 `-`를 글자로 쓰려고 붙인 것).
- 마지막은 **저장**(임시저장 아님). 실제 저장 시험은 사용자가 직접 한다.

## 엑셀 양식 (시트 하나, A1:C12)
| 줄 | B칸 | s-care 칸 |
|---|---|---|
| A1 | `○ 상담지  (대상자: 이름)` | (이름) |
| 2 | 가족사항 | `coFamMtrCn` |
| 3 | 사회참여 | `coSociPtinCn` |
| 4 | 경제상태 | `coEcoStaCn` |
| 5 | 주거환경 | `coHouEnvCn` |
| 6 | 고려사항(신체) `체크: 만성질환, …` | `coBdyDetailCd` 체크 (만성질환 B1, 장애 B2, 치아 B3, 시력 B4, 청력 B5, 보조기 B6, 기타 99) |
| 7 | 상담기록(신체) | `coBdyCnslRecCn` |
| 8 | 고려사항(정신) `체크: 인지기능저하, …` | `coMndDetailCd` 체크 (인지기능저하 M1, 치매의심 M2, 우울.불안 M3, 자살사고.시도 M4, 항정신성약물복용 M5, 미처방약물복용 M6, 잦은음주 M7, 기타 99) |
| 9 | 상담기록(정신) | `coMndCnslRecCn` |
| 10 | 강점 및 자원 | `coStrgRscCn` |
| 11 | 기타사항 | `coEtcCn` |
| 12 | 주요욕구 | `coImpDsrCn` |

칸은 B칸 제목으로 찾는다(줄이 밀려도 되게). 고려사항·상담기록은 영역(A칸 신체/정신) 아래 것으로 구분. 이름은 A1에서, 없으면 시트 이름·파일 이름(`이름_상담지.xlsx`)에서.

## 한 분 넣는 순서
1. 조사결과 작성중 목록에서 이름으로 찾기(없거나 두 분 이상이면 확인 필요). 방문일자·요청판정 읽기.
2. 상담지 상태 버튼이 `미입력`이 아니면 건너뜀(덮어쓰지 않음).
3. 상담지 창 열기 → 칸 채우기 → 상담자 넣기(`setupCounselUser`) → 저장 → 상담지 상태 글자가 바뀌면 완료.
4. 세 분씩 동시에(제공계획 입력과 같은 방식).

## 멈춤·확인 필요
- 상담자를 못 찾거나 여러 명 → 아무것도 저장하지 않고 멈춤.
- 목록에 없음, 방문일자 없음, 요청판정이 일반·중점이 아님, 엑셀 칸 못 읽음, 저장 실패 → 그 분만 확인 필요.

## 구성
- `scare_counsel.py`: 엑셀 읽기(`read_counsel`), 양식 만들기(`write_template`), s-care 넣기(`fill_one`, `run`). 크롬 연결·목록 열기·사용자 찾기는 `scare_plan.py` 것을 쓴다.
- `dropfiles.py`: 윈도 끌어다 놓기(ctypes, 새 라이브러리 없음).
- `tkui.py`/`api.py`: 새 화면.

## 시험
- 엑셀 읽기: 보내 준 양식 모양으로 만든 시험 파일(가짜 내용)로 칸 매핑, `'` 빼기, 체크 줄(빈 체크 포함), 이름 찾기.
- 장소 고르기, 시각 기본값, 폴더에서 상담지 파일 모으기.
- s-care 넣기는 사용자가 12월 시험 어르신으로 직접 시험.
